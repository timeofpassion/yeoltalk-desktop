# 슬랙 PC 0.1.7 검증 기록

- 2026-11-08: `apps/slack`만 변경. 다운로드 완료 후 숨김·입력 유휴 120초에 무인 설치·재실행하고, 사용 중에는 1분마다 판단해 최대 30분에 적용(10초 전 알림)한다.
- 시작 15초 후·10분마다 확인하며 준비·다운로드 중에도 공개 정책을 읽는다. `minVersion` 미달은 즉시 적용하고 정책 실패는 무시한다. 다운로드 취소·설치 실패 재시도도 검사했다. 서버 엔드포인트 구현은 이 작업 범위에 포함하지 않는다.
- 실제 앱 버전을 main의 실행 인자로 preload에 전달한다. 같은 출처의 60초 내 외부 열기 6번째·loadURL/reload 11번째부터 두 동작을 5분 차단하고 로그를 남긴다. iframe SPA·리다이렉트·상위 이동 시도에 대한 회귀 테스트를 추가했다.
- Node.js v24.18.0에서 `npm.cmd test` 47개 통과(실패 0), `git diff --check` 통과. PowerShell의 `npm.ps1` 실행 정책 때문에 동일한 npm 명령의 `.cmd` 진입점을 사용했다.
- 빌드·실제 Electron/직원 PC 설치 교체·운영 정책/피드 연동은 미실행. 커밋·푸시·PR 생성·릴리스 없이 `fix/desktop-auto-apply` 작업 트리에만 남겼으며, 루트 열톡 앱과 PR #9 브랜치는 수정하지 않았다.
- 공용 볼트는 이 환경에 `Y:` 드라이브가 없어 사전 조회·작업 후 노트 저장을 수행하지 못했다.
