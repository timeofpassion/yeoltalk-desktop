# 0.2.0 웹 미러링 앱 검증 — 2026-11-10

- 기존 0.1.8 기반. PR #9의 3탭 화면은 채택하지 않고 받은함 안정화·첨부/검증 패턴만 재사용했다.
- 같은 출처 전체 경로, 웹 공통 메뉴, 홈 유지, 로그인 직후 목적지 1회 복귀, 옛 열톡 변환, 같은 세션 새 창, 외부/메일 링크, 키보드/마우스 탐색, 문서 제목을 적용했다.
