# 열정 슬랙 0.1.1 수정 검증 — 2026-10-30

설치 후 인트라넷 공통 메뉴·자동 열톡 패널까지 표시되던 문제를 수정한다. 첫 문서 생성 시 공통 레이아웃 표시만 제한하고, 페이지 이동·팝업·Next.js 페이지 요청도 슬랙/열톡/로그인 범위로 제한한다. 허용 목록의 업무 문서 링크만 브라우저에서 본인 계정으로 연다. 대표실·급여 등과 알 수 없는 사내 경로는 브라우저 전달도 차단한다.

| 검증 | 범위·결과 |
|---|---|
| 자동검사 | 12개 통과. 공통 메뉴 숨김·로그인 복귀·페이지/SPA 이동 범위·기존 알림/업데이트 회귀 |
| 실제 Electron 렌더러 | 운영 레이아웃의 data-chrome/data-main 구조를 재현한 시험 데이터로 1360px/360px, SPA 이동, 새 문서 표시 시 메뉴/자동 패널 숨김·본문 입력 가능 확인 |
| 실제 요청 제한 | 격리된 HTTP 시험 서버·HTTPS 프로토콜 대역에서 로그인 완료 경로→슬랙 복귀, 금지 문서 이동·RSC 쿼리·RSC 헤더 차단, 일반 채팅 API 허용 확인. 회사 서버에 시험 요청을 보내지 않음 |
| 설치파일·업데이트 | NSIS 생성 성공, 123,683,643바이트. 시험 구버전→0.1.1 격리 다운로드 후 SHA-512 원본 일치. 설치 교체는 실행하지 않음 |
| 패키지 실행 | 실제 win-unpacked 실행파일에서 운영 로그인 화면과 빈 본인 계정 입력란 확인. 회사 계정으로 로그인하지 않음 |
| 운영 직원 계정 | 아직 재검증하지 않음. 시험 화면은 실제 직원 대화가 아님 |
| 보안 범위 | PC별 영속 프로필 유지, 비밀번호·직원 세션 미포함. 표시 제한 자체를 서버 권한 보장으로 주장하지 않음 |
| 서버 보완 | 별도 인트라넷 PR에서 대화 목록의 방 이름 기반 권한 예외 제거, 관리자/DM 비참여자 테스트 수행 |
| 운영 반영 | PR 승인·머지 전. 이 버전이 이미 자동 배포됐다고 주장하지 않음 |

개발자용 검증: npm test --prefix apps/slack, scripts/verify-slack-window.cjs의 격리 실행. 운영 데이터·DB 스키마 변경 없음. 이전 0.1.0 검증기록은 당시 범위로 보존한다.

최종 시험은 Windows 숨김 창의 GPU Viz 캡처 오류를 피하도록 시험 프로그램에만 소프트웨어 렌더러를 사용했다. 실제 패키지 설정은 변경하지 않았다. 화면 없는 캡처 오류와 운영 직원 계정의 업무 검증을 혼동하지 않는다.
