# 슬랙 PC 프로그램
- 기존 인트라넷 /slack 화면을 그대로 사용한다. 대화·업무 화면을 복제하지 않는다.
- 별도 오류 화면은 Pretendard 자체 호스팅, 브랜드 #E63329, 배경 #fff9f8, 본문 #0f172a.
- 앱·창·바로가기 이름은 슬랙. 홈·DM·베스타·활동·검색은 서버 /slack 화면을 사용한다.
- 기존 /talk 방 링크도 한 슬랙 창의 같은 대화로 연다. 별도 열톡 보조 창·메뉴를 만들지 않는다.
- 미구현 화면을 제품처럼 제시하지 않는다.
- 네트워크 실패 때 재연결 버튼을 보여 주고, 로그인·메시지 내용을 오류 로그에 넣지 않는다.
