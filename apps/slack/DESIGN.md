# 열정의시간 PC 프로그램
- 인트라넷 웹 전체를 그대로 표시한다. 공통 메뉴와 화면을 복제하거나 숨기지 않는다.
- 같은 출처의 모든 경로를 허용하며 실제 접근 권한은 서버가 정한다. 첫 화면은 /slack.
- 홈(/·/dashboard)은 그대로 표시한다. 로그인 직후 한 번만 원래 목적지 또는 /slack으로 복귀한다.
- 같은 출처의 새 창은 같은 세션의 앱 창, 외부 링크·mailto는 기본 브라우저로 연다.
- 앱·설치·바로가기 이름은 열정의시간. 창 제목은 웹 문서 제목을 따른다. 아이콘은 기존 회사 로고.
- 오류 화면은 Pretendard 자체 호스팅, 브랜드 #E63329, 배경 #fff9f8, 본문 #0f172a.
- 이동 후 다시 여는 규칙은 금지한다. 요청 전 차단기와 비공개 첨부 정책을 유지한다.
